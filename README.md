# EduPath

An AI-driven personalized learning planner. See the full write-up (architecture,
data flow, and VS Code setup) in the chat message this project was delivered with.

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000

All data is stored in your browser's localStorage under the key `edupath.state.v1`.
Use the "Start Over" button in the dashboard header to clear it.
